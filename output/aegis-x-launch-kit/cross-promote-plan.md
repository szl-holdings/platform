# Aegis ↔ SZL Holdings — Cross-promote plan

The subaccount split (`@szlholdings` parent + `@aegis_soc`, `@vessels_maritime`,
`@terra_re` subs) only works if the affiliate badge stays visible. The rule of
thumb: **one cross-post per week in each direction.**

## Weekly cadence

| Week day | From → To | Format |
|---|---|---|
| Tue | `@szlholdings` → quote-reposts the Aegis announcement | Quote-repost (within 60 min of Aegis post #1) |
| Wed | `@aegis_soc` → quote-reposts an `@szlholdings` doctrine post | Quote-repost with one operator-voice line |
| Fri | `@szlholdings` → spotlight reply on the Aegis architecture post | Reply, not repost (keeps comment surface alive) |
| Mon | `@aegis_soc` → quotes the SZL "decision can't be replayed" principle | Quote-repost framed for SOC operators |

## Bookkeeping

- Add the cross-post to the same content-calendar.md row so both accounts have
  a record.
- After 4 weeks, review which direction performed better (parent → sub vs.
  sub → parent) and re-balance the cadence.
- If `@szlholdings` crosses 1.5K followers before the subs cross 300, lean
  parent → sub. After parity, lean sub → parent.

## What *not* to do

- **Don't** post identical text on both accounts on the same day.
  Cross-promote, don't cross-spam.
- **Don't** drop the affiliate badge ("× SZL HOLDINGS" / "By @szlholdings")
  on the subaccount profile — that line is what makes the cross-promote
  legible to anyone who lands cold.
