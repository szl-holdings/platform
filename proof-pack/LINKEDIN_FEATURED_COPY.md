## Option 2: Technical Post (Shorter)

**Headline:** What "human-in-the-loop" actually looks like in production code

---

Not a checkbox. Not a UI prompt. A Covenant Policy gate baked into the execution contract — before the agent runs.

We built it into the SZL Holdings platform:

1. Signal arrives → classified and routed by policy
2. Workcell created → agent sequence defined, PCE contract attached
3. MirrorEval runs → counterfactual audit before any output is acted on
4. If policy threshold triggers → approval required before proceeding
5. Human confirms → proof packet signed, Evidence Ledger updated
6. Execution completes → outcome recorded with full chain-of-custody

The AI advises. Humans decide. The proof is cryptographic.

Code on GitHub. Architecture docs in the repo. Happy to do a technical walkthrough.
