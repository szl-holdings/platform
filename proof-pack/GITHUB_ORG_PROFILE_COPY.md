## What We Build

Enterprise AI isn't a product problem. It's a governance problem.

We built **A11oy** — a governed execution layer where every AI agent action flows through a Policy-Carrying Execution contract, every outcome is signed to an immutable Proof Chain, and every consequential step requires human confirmation.

**The result:** AI that advises at scale, with proof that it followed the rules.

## Technical Foundation

- **TypeScript monorepo** — 84 packages, 14 artifacts, pnpm workspaces + Turborepo
- **227 unit tests passing** — AEF package suite: contracts, policy-guard, evidence-ledger, retrieval-core, workflow-runtime
- **23 CI workflows** — build, lint, typecheck, security scan, E2E, deploy gates
- **132 database migrations** — PostgreSQL + Drizzle ORM, multi-tenant RBAC
- **0 credentials in source** — gitleaks + CodeQL + scheduled full-history secret scans
- **Production security** — OIDC/PKCE auth, 11-role RBAC hierarchy, AES-256 field encryption

## Governance Primitives

| Primitive | Purpose |
|-----------|---------|
| **Proof Chain** | Immutable audit trail — every action, every actor, every timestamp |
| **Covenant Policy** | Human-in-the-loop gates — AI cannot execute without human confirmation |
| **MirrorEval** | Counterfactual audit — second model validates output before execution |
| **PCE Contracts** | Policy-Carrying Execution — versioned, auditable execution contracts |
| **Evidence Ledger** | Signed proof packets — cryptographic receipts for every workcell |
