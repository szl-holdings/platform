## 0. THE MOAT — provenance discipline, stated explicitly (HARD RULES)

> **We NEVER adopt NO-LICENSE / unlicensed / GPL / AGPL / SSPL / "dark-web" / stolen code.**
> Tainted provenance destroys SZL's *verified-compute moat* (the whole pitch is "honest AI on honest power with clean provenance"). One copyleft or unlicensed file would poison the clean-room.
>
> **We adopt permissive-licensed IDEAS only — MIT / Apache-2.0 / BSD — verified by reading the actual `LICENSE` text/SPDX at HEAD, cited below.** We then **rebuild SZL-native, clean-room**, and carry an **attribution line** crediting the origin. Apache-2.0 inbound is fine for an idea-level rebuild; if we ever vendor an Apache-2.0 file verbatim we ship its `NOTICE` too. **ISC and 0BSD are permissive but are NOT in the founder's strict MIT/Apache/BSD allowlist** — I flag any such case explicitly and treat it as concept-only unless the founder widens the allowlist. **Specs/standards** (SLSA, RATS, in-toto attestation format, MCP) are *followed as standards* — we implement to the spec, we do not "copy code" — but I still record the spec's license.

**Doctrine v11 honesty rules carried through every recommendation below:**
- NO free-energy / over-unity / perpetual-motion claims — ever.
- **Λ = Conjecture 1** (advisory, NOT a theorem). **Khipu BFT = Conjecture 2** (conditional only).
- **locked-proven = 8.** **SLSA L1 honest** (we do not claim a level we cannot attest).
- **Joules MEASURED-only** — show "—" / "no measured exporter" rather than invent a number.
- **Sovereign = own-metal-only** (`sovereign:true` only when a local tier we own actually served).
- **Verified-compute is the moat.** **`szl-router` stays PRIVATE** — never published, never demoed externally, never described in a public surface.
- Every $/credit figure below is a labeled **ESTIMATE**.
- Research surfaces = **process-verification only** — no empirical psi / consciousness claims. **Cite, never plagiarize.**
