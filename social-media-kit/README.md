### CAROUSEL UPLOADS

Carousels are PDFs — you have two options to post them on social media:

**Option A: Upload PDF pages as images (recommended for X)**
- Use a tool like Adobe Acrobat, Preview (Mac), or any PDF viewer to export each page as a high-quality JPG/PNG
- Upload the images as a carousel or thread on X (up to 4 images per tweet)
- Suggested post captions are included in the tweets section

**Option B: Post on LinkedIn**
- LinkedIn natively supports PDF uploads as document carousels
- Click "Document" when creating a post → upload the PDF → LinkedIn shows it as a swipeable carousel
- Write the caption, then publish

**Suggested posting schedule:**
- Week 1, Day 1: Launch thread (5 tweets) + Carousel 1 (SZL Ecosystem)
- Week 1, Day 3: Carousel 2 (6 Lenses) + Lyte spotlight tweet
- Week 1, Day 5: Carousel 3 (From Noise to Signal) + Aegis spotlight tweet
- Week 2: Remaining spotlight tweets (one every 2 days)
