## SZL Flagship Homepage Hierarchy

### Above the Fold
1. **Category claim:** "Governed Decision Infrastructure"
2. **Subhead:** "The structural layer between signal detection and action execution. Nine steps. Full accountability. Every domain."
3. **Primary CTA:** "See the Decision Theater" (live interactive demo)
4. **Secondary CTA:** "Read the Architecture" (trust center / docs)

### Section 1: The Problem
- "AI is making more decisions. Who governs them?"
- Three-panel contrast: Dashboard (shows what happened) → Copilot (suggests what to do) → SZL (governs what gets done)

### Section 2: The Loop
- Interactive nine-step visualization (Signal through Learning)
- Each step clickable with real data examples
- Inspired by Stripe's API documentation — show the structure, not just describe it

### Section 3: The Primitives
- Six primitive cards with technical depth
- Event Fabric, Decision Simulation, Covenant Policy, Workflow Engine, Proof Chain, Outcome Graph
- Each card: one-sentence description + "See the code" link to GitHub

### Section 4: Domain Packs
- Grid of domain applications (Aegis, Vessels, Terra, etc.)
- Each card: domain icon, one-liner, "Explore" link
- Conveys breadth without sprawl

### Section 5: Trust
- Self-serve trust center link (inspired by Vanta)
- Compliance badges (SOC 2 Type II target, encryption standards)
- Open-source governance primitives (link to GitHub)
- Security posture summary

### Section 6: For Investors
- Architecture documentation
- Platform primitives reference
- Team and vision
- "Request diligence packet" CTA
