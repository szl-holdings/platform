# Release Log

**Owner:** CTO / Founder
**Last updated:** April 2026

This file is the canonical record of all production releases. Update it immediately after every production promotion. It is the "What Changed" data source for the Founder Control Room.

---

## Format

```
## v{MAJOR}.{MINOR}.{PATCH} — YYYY-MM-DD

| Field | Value |
|-------|-------|
| Release | v{MAJOR}.{MINOR}.{PATCH} |
| Date | YYYY-MM-DD HH:MM UTC |
| Commit SHA | <full 40-char SHA> |
| Rollback SHA | <previous release full SHA> |
| Deployed by | <name> |
| Staging verified | yes / no (with justification if no) |
| Smoke tests | PASS / FAIL (with details if FAIL) |
| Affected services | <comma-separated list> |
| Summary | <one-line description> |
| Known issues | <none or description> |
```
