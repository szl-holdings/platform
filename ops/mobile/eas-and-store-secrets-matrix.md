# EAS Profiles and Store Secrets Matrix

Updated: 2026-04-16

## Scope

This document covers CORTEX (`artifacts/cortex-mobile`) — the only mobile app in active release preparation. All other mobile apps are deferred or archived.

---

## EAS Build Profiles

Defined in `artifacts/cortex-mobile/eas.json` (must be created before first build):

```json
{
  "cli": {
    "version": ">= 7.0.0"
  },
  "build": {
    "development": {
      "distribution": "internal",
      "ios": { "simulator": true },
      "android": { "buildType": "apk" },
      "env": {
        "EXPO_PUBLIC_API_URL": "https://<dev-replit-domain>/api"
      }
    },
    "preview": {
      "distribution": "internal",
      "ios": { "resourceClass": "m-medium" },
      "android": { "buildType": "apk" },
      "env": {
        "EXPO_PUBLIC_API_URL": "https://<staging-domain>/api"
      }
    },
    "production": {
      "autoIncrement": true,
      "credentialsSource": "remote",
      "ios": { "resourceClass": "m-medium" },
      "env": {
        "EXPO_PUBLIC_API_URL": "https://api.szlholdings.com/api"
      }
    }
  },
  "submit": {
    "production": {
      "ios": {
        "appleId": "<APPLE_ID>",
        "ascAppId": "<ASC_APP_ID>",
        "appleTeamId": "<TEAM_ID>"
      },
      "android": {
        "serviceAccountKeyPath": "./google-service-account.json"
      }
    }
  }
}
```

## Secrets Inventory

### EAS / Expo Secrets (set via `eas secret:create` or expo.dev dashboard)

| Secret Name | Required | Owner | Purpose |
|-------------|----------|-------|---------|
| `EXPO_TOKEN` | Yes | Expo account | CI-triggered EAS builds |
| `SENTRY_DSN` | Recommended | Sentry project | Crash reporting |
| `EXPO_PUBLIC_API_URL` | Yes | Set per profile | Points mobile to correct API backend |

### Apple / iOS Secrets

| Item | Source | Where Set | Notes |
|------|--------|-----------|-------|
| Apple Developer Apple ID | developer.apple.com | `eas.json` submit.production.ios.appleId | Your Apple account email |
| Apple Team ID | developer.apple.com → Membership | `eas.json` submit.production.ios.appleTeamId | Format: `ABCDE12345` |
| ASC App ID | App Store Connect → App Information | `eas.json` submit.production.ios.ascAppId | 10-digit number |
| APNs Auth Key (.p8) | developer.apple.com → Keys | Uploaded to Firebase Console | One key covers all apps |
| Distribution Certificate | Auto-generated by EAS | EAS remote credentials | Never delete from Expo account |
| Provisioning Profile | Auto-generated by EAS | EAS remote credentials | Managed automatically |

### Android / Google Secrets

| Item | Source | Where Set | Notes |
|------|--------|-----------|-------|
| Upload Keystore | Auto-generated by EAS on first production build | EAS remote credentials | Back up via `eas credentials` |
| Google Service Account JSON | Google Play Console → API Access | `./google-service-account.json` (gitignored) | One account for all apps |
| `google-services.json` | Firebase Console → Android app | `cortex-mobile/` root (gitignored) | FCM push notifications |
| `GoogleService-Info.plist` | Firebase Console → iOS app | `cortex-mobile/` root (gitignored) | APNs push notifications |

## `.gitignore` Requirements

These files must never be committed. Verify each is present in `.gitignore`:

```
# Firebase credentials
google-services.json
GoogleService-Info.plist

# Play Store service account
google-service-account.json

# EAS local credentials cache
.expo/
```

## CI Secrets (GitHub Actions)

If builds are triggered from CI instead of local EAS:

| Secret Name | GitHub Secrets Path | Value Source |
|-------------|---------------------|--------------|
| `EXPO_TOKEN` | Repository → Secrets | expo.dev → Account → Access tokens |
| `APPLE_TEAM_ID` | Repository → Secrets | developer.apple.com → Membership |
| `ASC_APP_ID` | Repository → Secrets | App Store Connect |
| `GOOGLE_SERVICE_ACCOUNT_JSON` | Repository → Secrets | Google Play Console (base64-encoded) |

---

## Secrets Rotation Policy

| Secret | Rotation Trigger | Action |
|--------|-----------------|--------|
| EXPO_TOKEN | Annually or on team change | Revoke old token, create new, update CI |
| Upload Keystore | Never (loss = resubmit to Play Store) | Back up via `eas credentials --platform android` |
| APNs Key | If key is revoked in Apple portal | Regenerate in Apple portal, upload to Firebase |
| Firebase configs | On project recreation | Re-download and replace local files |
