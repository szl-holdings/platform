## Technical Architecture

```
Stack:        TypeScript · React · Vite · Express 5 · PostgreSQL · Drizzle ORM · Expo
Monorepo:     pnpm workspace — shared libraries, shared UI, shared database layer
API:          1,618+ endpoints across REST, GraphQL, and WebSocket
Database:     446 tables, one shared PostgreSQL schema
Mobile:       8 Expo React Native apps (iOS + Android ready)
AI:           Governed advisory agents with source citations and confidence scores
Auth:         RBAC with session management
Deployment:   Replit Autoscale (production), single-command dev environment
```

### Key Architecture Decisions
- **One monorepo, not microservices** — every improvement compounds across every platform
- **AI governance by design** — agents advise, humans decide, everything is audited
- **Evidence-backed decisions** — every AI recommendation includes source citations
- **OSINT-only** — no classified data dependencies, no government clearance required
- **Explicit over implicit** — platform state is always visible, failures surface
