## Architecture Philosophy

I build systems, not features. Every product in the SZL ecosystem shares one intelligence backbone, one design system, one execution fabric, and one data layer. New verticals compound the existing infrastructure investment rather than duplicating it.

The documentation is written before the implementation. The architecture is explicit, not emergent.

**Principles that show up in every codebase I produce:**
- Explicit over implicit — state, data freshness, and model confidence are always visible
- Advisory before autonomous — AI outputs are recommendations; humans confirm consequential actions
- Traceability as a feature — the audit trail is an operational tool, not a compliance artifact
- Premium restraint in design — density with clarity, not decoration
