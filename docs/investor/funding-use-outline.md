- Full platform ecosystem (5 domain platforms + execution fabric + corporate site + founder site)

## Funding Objectives

The primary objectives of the first external funding round are:

### Objective 1: Revenue Activation (Priority)

Getting the first paying customer is the most important milestone. Funding accelerates:
- Lyte commercial launch — pricing finalization, billing activation, first sales motion
- Vessels live data integration — AIS data feed subscription ($15–40K/year for quality feeds)
- Carlota Jo client intake activation — billing, domain, first advisory clients

### Objective 2: Live Data Integration

Platform demonstrations with seeded data are compelling. Platforms with live data pipelines are fundable in the next round.
- AIS data feed for Vessels (real-time vessel positions, voyage data)
- Expanded Lyte connector library (beyond the 40+ stubs — fully tested live connections)
- Sanctions list API subscription (Vessels compliance layer)
- Enhanced Terra data coverage (national expansion beyond NYC)

### Objective 3: Compliance Foundation

Beginning the compliance track is required for enterprise sales in regulated verticals:
- SOC 2 Type I audit preparation (6–9 months)
- Penetration testing engagement
- Formal security policy documentation (beyond current engineering practices)
- FedRAMP readiness scoping (Aegis — longer track)

### Objective 4: Go-to-Market

The platform needs its first enterprise development motion:
- Founder + 1 enterprise development resource
- Conference presence (maritime: Posidonia; security: RSA; real estate: ICSC)
- LinkedIn / content marketing infrastructure

### Objective 5: Infrastructure Hardening

Pre-revenue infrastructure gaps:
- Redis for production session store
- Sentry error tracking (frontend + backend)
- Production monitoring and alerting
- CORS configuration for production domains

## Priority Sequence

If funding is constrained, the priority sequence is:

1. **Revenue activation** — First Lyte commercial customer. Everything else follows from here.
2. **Live AIS data** — Vessels becomes significantly more compelling with live fleet data
3. **SOC 2 preparation** — Required for enterprise sales in security and financial services
4. **Go-to-market resource** — One enterprise development hire after first revenue
5. **Infrastructure hardening** — Parallel with GTM ramp

---

## What Funding Does Not Buy

- Engineering time to rebuild the platform (it is already built)
- Core architecture decisions (already made and validated)
- A pivot (the platform thesis is confirmed by the codebase)

Funding buys activation, live data, compliance, and distribution — not construction.
