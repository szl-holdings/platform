# SZL Holdings — Investor Demo Script
**Version:** April 17, 2026  
**Format:** ~25 minutes, screen-share, guided click-path  
**Audience:** Institutional investors / strategic partners  

---

## Before You Start (Presenter Setup)

1. Sign in at any SZL Holdings app once:  
   `https://<your-domain>/api/login`  
   This sets a session cookie that works across all apps.

2. Open all tabs in advance:
   - Tab 1: `/` — SZL Holdings landing
   - Tab 2: `/command/strategy` — Unified Command (Strategy view)
   - Tab 3: `/command/operations` — Unified Command (Operations view)
   - Tab 4: `/pulse/?demo` — Pulse briefing
   - Tab 5: `/vessels/` — Vessels landing
   - Tab 6: `/aegis/` — Aegis landing
   - Tab 7: `/carlota-jo/` — Carlota Jo landing

3. For Pulse demo mode (works without sign-in): navigate to  
   `/pulse/?demo` — the demo flag persists for the session.

## Segment 3 — Pulse: The Intelligence Layer (~5 min)
**URL: `/pulse/?demo`**

Switch to the Pulse tab.

> "Pulse is the executive intelligence layer. Every morning, seven specialized AI agents each brief their domain — maritime, security, real estate, legal, financial, platform. Alloy synthesizes them into one product."

Point to the headline: "Bay of Bengal Corridor Presents Near-Term Fleet Exposure; Sanctions Screening Gap Identified."

> "Two recommendations flagged P0 this morning. Route deviation for the fleet — 6-hour window. And an OFAC partial-match on a counterparty in Monday's contract closing — that goes to the General Counsel today."

Click on the **Maritime Operations** section to expand it.

> "Every section includes the key judgment, narrative, key findings ranked by severity, assumptions, and intelligence gaps. This isn't a summary. It's a tradecraft product — the same format used by intelligence services."

Point to the confidence score (HC · 79%) and risk badge (HIGH).

> "Confidence scoring is first-class. If Helmsman doesn't have enough evidence to be confident, it says so — and flags the gap instead of hallucinating certainty."

Click **"Dissent Channel"** in the sidebar.

> "This is the dissent channel. Any agent — or any analyst — can file a formal dissent against a key judgment. The opposing view is logged, attributed, and tracked. If the dissenter turns out to be right, the system learns."

Click **"Briefing Library"** in the sidebar.

> "Every briefing is archived, searchable, filterable by domain and risk level. Intelligence products accumulate over time — the system builds context about your portfolio."
