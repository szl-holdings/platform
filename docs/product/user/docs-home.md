## Platform at a Glance

**SZL Holdings** builds governed decision infrastructure — the structural layer between signal detection and action execution that enforces governance, attribution, and outcome tracking on every consequential decision.

The platform is organized as:

| Layer | Product | Role |
|---|---|---|
| Platform | SZL Holdings | Governed decision layer |
| Flagship command | Lyte | Operator command surface |
| Execution fabric | Alloy | Governance backbone |
| Mobile command | CORTEX | iOS + Android unified command |
| Domain packs | Aegis, Vessels, Terra, PRISM Counsel, Carlota Jo | Domain intelligence |

The governed decision loop runs across all products:
```
Signal → Context → Recommendation → Simulation → Policy → Execution → Proof → Outcome → Learning
```
