## 2. Minimum Security Baseline (Non-Negotiable)

These controls must be active in every environment (dev, staging, production). A workload that does not satisfy these is **not production-eligible**.

| # | Control | Mechanism | Enforced By |
|---|---------|-----------|------------|
| B001 | No hardcoded secrets | gitleaks, secret-scan CI | CI gate — blocks merge |
| B002 | All GitHub Actions pinned to SHA | Workflow review | Code review; future: pin-action CI check |
| B003 | `packages/security-headers` applied | Middleware import in golden path | Code review; golden path default |
| B004 | Auth middleware on all API routes | `packages/auth-shared` + tenant-scope | Golden path default |
| B005 | Rate limiting on public endpoints | express-rate-limit | Golden path default |
| B006 | Structured audit log for consequential actions | `lib/audit` | Golden path default for agent workers |
| B007 | Dependency review on all PRs | `dependency-review.yml` | CI gate |
| B008 | CodeQL SAST on all PRs | `codeql.yml` | CI gate |
