# Monthly Publishing Rhythm

## Weekly
- [ ] 1+ article published (blog/insight)
- [ ] Social distribution of content
- [ ] Analytics review (WAU, leads, errors)
- [ ] Help center content check

## Monthly
- [ ] Release recap published
- [ ] Trust update published (if changes)
- [ ] Newsletter sent
- [ ] Product review meeting
- [ ] Content calendar updated
- [ ] Lead pipeline reviewed
- [ ] Flag registry reviewed

## Quarterly
- [ ] Benchmark report published
- [ ] Full flag registry audit
- [ ] Compliance roadmap updated
- [ ] Integration catalog reviewed
- [ ] Academy content refreshed
- [ ] Feedback trends analyzed
- [ ] Post-release reviews summarized

## Annually
- [ ] Security audit/penetration test
- [ ] Full platform architecture review
- [ ] Compliance certification updates
- [ ] Content strategy review
- [ ] Brand refresh evaluation
