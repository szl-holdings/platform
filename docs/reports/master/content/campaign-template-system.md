# SZL Holdings — Campaign Template System

## Template Library

### 1. Product Launch Campaign
**Trigger:** New product or major feature release
**Duration:** 2 weeks
**Auto-generates:**
- Canonical article: "[Product] is live — here's what it means for [audience]"
- X pack: Launch thread (7+ posts) + 5 singles + 3 follow-ups
- LinkedIn pack: Executive announcement + PDF document post + carousel
- Medium pack: Cross-post with canonical URL
- Substack pack: Full post + 3 Notes
- PDF/carousel: Product overview PDF
- Site CTA: Updated hero, product page, demo link
- Linktree: Featured launch link at top

### 2. Feature Drop Campaign
**Trigger:** Notable feature addition
**Duration:** 1 week
- Canonical article: "Now available: [Feature]"
- X: Thread (5 posts) + 3 singles
- LinkedIn: Feature highlight post + before/after visual
- Substack: Note with feature link
- PDF: Feature one-pager

### 3. Thesis / POV Campaign
**Trigger:** Industry opinion or framework piece
**Duration:** 2 weeks
- Flagship essay (2000+ words)
- X: Thread distillation + 5 quote-card singles
- LinkedIn: Executive text post + PDF framework doc
- Medium: Full essay with canonical URL
- Substack: Newsletter edition + Notes
- PDF: Framework visual deck (8-12 slides)

### 4. Industry Pain Point Campaign
**Trigger:** Market problem worth addressing publicly
**Duration:** 1 week
- Short article: "[Industry] is broken — here's why"
- X: Pain-point thread + 3 contrast singles
- LinkedIn: Problem statement post
- Substack: Note
- No PDF needed

### 5. Case Study / Scenario Campaign
**Trigger:** Real or illustrative use case
**Duration:** 1 week
- Case study article with problem/solution/result
- X: Results thread + 3 singles
- LinkedIn: Case study summary + PDF
- PDF: Case study one-pager

### 6. Build-in-Public / Founder Update
**Trigger:** Monthly or milestone-based
**Duration:** 3 days
- Founder memo (short, personal)
- X: Thread (transparent metrics, learnings)
- LinkedIn: Personal reflection post
- Substack: Note
- No PDF needed

### 7. Report / Whitepaper Campaign
**Trigger:** Research or analysis complete
**Duration:** 2 weeks
- Full report (owned site)
- X: Key findings thread + infographic singles
- LinkedIn: Executive summary + PDF download
- Medium: Summary article
- Substack: Newsletter with key insights
- PDF: Full downloadable report

### 8. Event / Demo Week Campaign
**Trigger:** Scheduled demo or event
**Duration:** 1 week pre + 1 week post
- Pre-event: Teaser content across all platforms
- Event: Live coverage (X thread)
- Post-event: Recap across all platforms
- Linktree: Event registration link

### 9. Trust / Engineering Discipline Campaign
**Trigger:** Security, compliance, or quality milestone
**Duration:** 1 week
- Article: Trust/security deep dive
- X: Thread on discipline practices
- LinkedIn: Professional credibility post
- No PDF needed

### 10. Hiring / Team / Company Signal Campaign
**Trigger:** Team growth, culture milestone
**Duration:** 3 days
- Founder note
- X: 3 singles
- LinkedIn: Team/culture post
- No PDF needed

## Campaign Execution Workflow

```
1. Select campaign template
2. Fill template variables (product, audience, key messages)
3. Auto-generate content outlines per platform
4. Review and refine in admin panel
5. Schedule publication across platforms
6. Execute day-by-day
7. Track via UTMs (dos_campaign_links)
8. Review analytics post-campaign
```
