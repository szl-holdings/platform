# SZL Holdings — 180-Day Growth Plan

## Phase 1: Foundation (Days 1-30)
**Objective:** Establish presence, publish foundational content, build initial audience

- Launch on all platforms (X, LinkedIn, Medium, Substack)
- Publish 7 foundational posts (one per product/persona)
- Generate profile kit (avatars, banners, bios)
- Establish weekly publishing cadence
- Set up analytics tracking

## Phase 2: Depth (Days 31-60)
**Objective:** Build domain expertise reputation, start lead generation

- Domain-specific deep dives per product lane
- Case study scenarios and framework articles
- Start monthly report cadence
- Begin build-in-public series
- Optimize based on Month 1 analytics

## Phase 3: Compound (Days 61-90)
**Objective:** Convert attention to inbound leads and demo requests

- Quarterly thought-leadership report
- Partner/ecosystem content
- Launch playbooks for features
- Conversion-focused CTAs across all content
- First quarterly review and pivot

## Phase 4: Scale (Days 91-120)
**Objective:** Systematize and automate content production

- Recurring pillar series (automated scheduling)
- Content template system operational
- Campaign-driven content bursts
- A/B test hooks, formats, CTAs
- Build content team playbook

## Phase 5: Authority (Days 121-150)
**Objective:** Establish SZL as domain authority

- Industry reports and market intelligence
- Speaking/event content
- Guest contributions
- Partnership announcements
- Investor-ready content portfolio

## Phase 6: Flywheel (Days 151-180)
**Objective:** Self-sustaining content engine with compounding returns

- Community engagement driving content ideas
- User-generated signals feeding content pipeline
- Automated analytics → content recommendations
- Predictable lead flow from content
- Content-to-product feedback loop
