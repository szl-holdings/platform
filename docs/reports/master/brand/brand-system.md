# SZL Holdings — Brand System

## Design Principles
- Premium, restrained, modern
- High contrast, dark-first
- Clear hierarchy
- No clutter, no childish visuals
- Consistent family look across all lanes

## Color System

| Token | Hex | Usage |
|-------|-----|-------|
| Background Primary | #080c14 | Main app backgrounds |
| Background Secondary | #070a10 | Panels, sidebars |
| Amber (Premium) | #d4a054 | Gold accents, highlights, CTAs |
| Risk Red | #c45a4a | Alerts, critical status |
| Signal Orange | #c8953c | Warnings, attention items |
| Intelligence Purple | #8b7ac8 | AI, intelligence indicators |
| Motion Blue | #4a90b8 | Active states, progress |
| Text Primary | White / #f0f0f0 | Body text |
| Text Secondary | #9ca3af | Labels, metadata |

### Banned Colors
- `text-red-400` (except status chips)
- `text-orange-400` (except status chips)
- `text-emerald-400` (except status chips)

## Typography
- Display: System serif (Cormorant Garamond on Carlota Jo)
- Body: Inter / system sans-serif
- Mono: JetBrains Mono / system monospace
