# Demo Asset Policy

> SZL Holdings Platform Governance · April 2026

---

## What Is a Demo Asset

A demo asset is any artifact created specifically to demonstrate the SZL Holdings platform to an external audience: investors, design partners, enterprise evaluators, or press.

Demo assets include:
- Demo data seeds and seed scripts
- Investor presentation decks
- Demo walkthrough scripts
- Screen recordings and product videos
- Screenshot collections for investor materials
- Live demo environment access credentials

---

## Demo Data Governance

### Seeding

All demo data is generated by `scripts/seed-demo-canonical.sh` (alias: `pnpm seed:demo`). The seed script produces:
- A consistent set of org, user, tenant, and domain-specific records
- Named personas (test users) with realistic but fictional data
- No PII from real customers

### Demo Data Rules

| Rule | Requirement |
|------|-------------|
| Source | Seed scripts only — no manual data entry |
| PII | No real customer names, emails, addresses, or phone numbers |
| Financial data | Fictional — no real financial data, real fund performance, or real transaction histories |
| Vessel names / IMO numbers | Fictional or public AIS data (non-sensitive) |
| Real estate addresses | Fictional or anonymized public records |
| Legal matters | Entirely fictional — no real case references |
| Refresh cycle | Reseed before each major investor demo |

## Demo Environment

| Environment | URL | Access |
|-------------|-----|--------|
| Development | Replit workspace | Internal only |
| Staging | Staging Replit deployment | Internal + trusted evaluators |
| Production | szlholdings.com | Public-facing |

Access credentials for staging demos are provided under NDA. They are never committed to the repository.

---

## Demo Video and Recording Policy

- Screen recordings for public/investor use require approval before distribution
- No recordings of internal meetings or internal-only screens
- Product demo videos are stored as artifacts (see `artifacts/szl-demo-video/`)
- Raw recordings are stored in `demo-assets/` (gitignored for sensitive content)
