# CITATIONS_BIBLIOGRAPHY.md — Primary-source citation index (alphabetical)

`ANCIENT_PRIMITIVES.md` (v1) + `ANCIENT_PRIMITIVES_v2.md` (v2). Reachable via Cambridge /
Oxford / Princeton / Brill / JSTOR / university repositories / peer-reviewed journals.
