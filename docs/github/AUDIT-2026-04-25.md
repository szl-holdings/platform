### 10. `secret-scan-scheduled.yml` — Hardcoded `ref: main` on a `master` Repo (FIXED)

**Location:** `.github/workflows/secret-scan-scheduled.yml`

**Found:** The scheduled secret scan hardcoded `ref: main` when checking out, but the repo's default branch is `master`. On a schedule trigger, this would check out `main` (potentially failing or scanning the wrong history).

**Fixed:** Changed to `ref: ${{ github.event.repository.default_branch || 'master' }}` so it always scans the actual default branch.

**Also fixed:** The `upload-sarif` action in this workflow pinned an older SHA (`v3.28.13`). Updated to match the version used across all other workflows (`v3.35.2`, SHA `ce64ddcb0d8d890d2df4a9d1c04ff297367dea2a`).
