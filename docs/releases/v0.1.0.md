# Release Notes — v0.1.0

**Release:** v0.1.0  
**Date:** 2026-04-01  
**Type:** Initial Public Platform Release

---

## Summary

v0.1.0 is the first formal public release of the SZL Holdings platform ecosystem. It represents the completion of the foundational architecture build phase — a fully-implemented, production-grade, multi-product software platform.

This release is pre-commercial. All platforms operate on seeded/demo data (clearly labeled in each UI). Revenue activation (Stripe billing), live data feeds, and enterprise deployment are Phase 2 milestones.

### Infrastructure

- PostgreSQL schema with full domain isolation (Drizzle ORM)
- OpenID Connect (PKCE) authentication with org-scoped RBAC
- WebSocket real-time layer with HMAC-signed tickets
- Express API server serving all platform backends
- Azure Bicep IaC templates ready for enterprise deployment
- Stripe billing infrastructure (configured, not activated)
- Multi-provider email (Resend → SendGrid → SMTP failover)
- Branded PDF generation (pdfkit, 8 templates)
- Salesforce AppExchange + Jira Marketplace package stubs

## Known Limitations (Honest)

- All platform data is seeded/demo (except Terra's live NYC distress pipeline)
- Stripe billing is built but not activated
- No paying customers
- No SOC 2 certification
- AIS data in Vessels is simulated
- Redis session store not configured (in-memory only)
- Sentry error tracking not configured

These limitations are documented in `/docs/investor/readiness-gaps.md`. None represent architectural risk.
