7. DEPLOYMENT RECOMMENDATIONS BY SURFACE
==================================================

Use this deployment model:

STATIC
Use Static deployment for:
- SZL Holdings public brand surface
- Carlota Jo public marketing surface
- Founder pages
- Alloy public overview pages if they remain frontend-only
- documentation / case studies / insights if static

AUTOSCALE
Use Autoscale for:
- Lyte app routes
- Vessels app routes
- Alloy APIs or authenticated app behavior
- any interactive surface with auth, APIs, or user-specific data

SCHEDULED
Use Scheduled deployments for:
- recurring scans
- daily digests
- readiness checks
- workflow polling
- report generation
- routine maintenance or summary jobs

RESERVED VM
Use Reserved VM only if truly necessary for:
- always-on worker processes
- long-running connected services
- bots or services that cannot sleep
- memory-intensive persistent jobs

RULE
Do not default to Reserved VM just because it sounds serious.
Use the lightest deployment type that actually fits the product need.

==================================================
