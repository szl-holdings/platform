==================================================

Create:
/services/ingestion

Build a real ingestion framework.

A. CSV Upload Ingestion
POST /api/ingestion/upload
- parse CSV
- normalize headers
- validate rows
- normalize address
- map borough/county
- infer NY when applicable
- classify distress type
- dedupe by address + filing date + type
- upsert into distress_properties

B. Scheduled Ingestion
- node-cron based scheduler
- support every 6h or 12h job runs
- record job metadata in ingestion_jobs

C. Source Adapters
Design adapters for:
- NYC public property / record exports
- New York State public datasets
- county exports
- manual file imports

D. Normalization Rules
- address casing normalization
- borough aliases normalized
- county normalization
- dedupe strategy
- source provenance retained

Do not fake live scraping.
Build clean ingestion interfaces, upload flows, and adapters so real sources can be connected safely and legally.
