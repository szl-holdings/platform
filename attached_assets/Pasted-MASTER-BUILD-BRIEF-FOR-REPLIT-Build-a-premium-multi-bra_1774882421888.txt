- Use Supabase auth
- Roles: public, authenticated, member, client, editor, admin, super_admin
- Enable RLS on all protected tables
- Default deny
- Public reads only for published public content
- Org-scoped data must check memberships
- Client portal must only show that client’s records
- Keep secrets server-side only

A feature is only done when:

- mobile works
- data model exists
- permissions are enforced
- loading/empty/error/success states exist
- analytics are wired where relevant
- copy is premium
- SEO is set
- admin editability exists where needed
