SZL HOLDINGS ECOSYSTEM — MASTER BUILD PAYLOAD

MISSION  
Evolve the entire SZL ecosystem into a premium, production-grade family of apps and websites with one shared design system, one shared technical spine, one shared admin/content layer, and distinct brand identities per lane.

APPS / WEBSITES IN SCOPE  
- SZL Holdings — portfolio HQ / umbrella brand  
- Vessels — maritime command platform  
- INCA — intelligence / cyber / signal platform  
- Terra — real estate broker platform  
- Carlota Jo Consulting — luxury advisory / service brand  
- Stephen Site — authority, thought leadership, and selected work  
- Admin — internal content and operations layer  

GLOBAL STANDARD  
Everything must feel:  
- premium  
- intentional  
- modern  
- credible  
- commercially real  
- visually cohesive  
- restrained, not noisy  

NON-NEGOTIABLE RULES  
- No placeholder text  
- No fake dashboards  
- No fake metrics  
- No empty routes or dead pages  
- No generic startup template look  
- No exposing protected data  
- One shared design system across all brands  
- Carlota Jo is the public brand, not Rosa Lutar  
- If a feature is not real yet, hide it instead of faking it  
- Prioritize clean, premium, maintainable execution over flashy complexity

- Framer Motion

BRAND / LANE POSITIONING  

SZL Holdings  
Role: umbrella brand, ecosystem HQ, strategic portfolio surface  
Must feel: premium, strategic, structured, executive, investor-ready  
Homepage must include: ecosystem hero, venture overview strip, roadmap snapshot, updates section, strong CTA  
Core copy: Structured ventures for modern systems, services, and execution  
CTA: Explore the portfolio  

Vessels  
Role: maritime command platform  
Must feel: technical, map-forward, command-center-like, premium  
Homepage must include: hero, map/product visual, capabilities, use cases, trust section, demo CTA  
Core copy: Maritime visibility, built for command  
CTA: Request a private demo  

INCA  
Role: intelligence / cyber / signal platform  
Must feel: dark, sharp, disciplined, secure  
Core copy: Intelligence with structure  
CTA: Request access  

Terra  
Role: real estate broker platform  
Must feel: high-end, modern, professional (NOT Zillow clone)  
Homepage must include: listing showcase, broker tools positioning, future map/search readiness  
Core copy: Real estate intelligence and brokerage tools, built for clarity and execution  
CTA: Explore listings  

Carlota Jo Consulting  
Role: luxury advisory brand  
Must feel: calm, discreet, elegant, bespoke  
Homepage must include: services, approach, trust, private inquiry  
Core copy: Bespoke advisory for clients who value discretion and precision  
CTA: Inquire privately  

Stephen Site  
Role: authority / thought leadership platform  
Must feel: sharp, credible, modern  
Homepage must include: work, frameworks, writing, contact  
Core copy: Systems, visibility, and execution for modern operations  
CTA: Start a conversation  

Admin  
Role: CMS and operations layer  
Must support: content CRUD, media, SEO, navigation, forms, publish/draft, audit
