DESIGN + COPY DIRECTION MASTER PAYLOAD

MISSION
Take the existing ecosystem and elevate it from “well-built” to “category-defining.”
This payload governs:
- visual identity
- brand behavior
- interface personality
- UX tone
- content tone
- copywriting standards
- conversion language
- motion language
- photography/illustration direction
- page composition
- emotional feel per lane

This must feel intentional, expensive, and world-class.
Do not generate generic startup design.
Do not generate hype-heavy AI slop.
Do not generate cliché luxury aesthetics.
Do generate disciplined, premium, intelligent design with strategic clarity.

==================================================

==================================================

The ecosystem should feel like the intersection of:
- Linear’s clarity, focus, and momentum

It should never feel:
- busy

- crypto-bro

- fake luxury
- overdesigned
- corporate bland
- AI-generated in tone

==================================================
MASTER VISUAL SYSTEM
==================================================

Create one core design language shared across all lanes.

VISUAL PRINCIPLES
1. Use clean geometry and disciplined spacing.
2. Favor strong hierarchy over decoration.
3. Use contrast and layout rhythm to create authority.
4. Let whitespace do real work.
5. Use motion sparingly and only to reinforce meaning.
6. Every component should look production-grade and intentional.
7. The interface should feel fast before it even loads.
8. Prioritize elegant structure over visual excess.

TYPOGRAPHY
Use a premium digital/system-forward pairing.
Direction:
- primary sans should feel modern, technical, crisp, and premium
- mono should be used sparingly for metadata, labels, system tags, and technical moments
- headings should feel controlled, not shouty
- body copy should be highly readable and calm

Typography behavior:
- tighter tracking for high-authority headings
- slightly looser body rhythm for premium readability
- clear hierarchy between eyebrow / heading / subheading / body / caption / label
- no oversized marketing fluff headlines unless earned

LAYOUT
- use strong grid discipline
- embrace asymmetry only when it improves premium feel
- sections should breathe
- keep content width controlled
- cards should align perfectly
- spacing must feel systemized, not improvised
- mobile layouts must preserve elegance, not just collapse responsively

SURFACES
- use layered surfaces with subtle contrast
- avoid tacky glassmorphism unless extremely restrained
- avoid exaggerated gradients
- use depth sparingly
- dark mode should feel rich, not neon
- light mode should feel premium, not sterile

MOTION
- motion should communicate state, hierarchy, and confidence
- prefer subtle fade, elevation, scale, and directional transitions
- avoid bouncy animation
- avoid gratuitous parallax
- hero motion must feel expensive and controlled
- loading states should feel polished and lightweight

ICONOGRAPHY
- use a consistent icon family
- icons should be clean, minimal, and aligned to the design system
- no mixed icon styles
- use icons for utility, not decoration overload

==================================================
MASTER COLOR PHILOSOPHY
==================================================

Build one master color system, then create per-lane accents.

GLOBAL BASE
- neutral-first palette
- rich blacks / charcoals / graphite for dark surfaces
- warm off-whites / stone / soft gray for light surfaces
- high-contrast text but never harsh
- accents used intentionally, not everywhere

COLOR USAGE RULES
- one primary accent per lane
- one secondary support accent max
- color should indicate identity, not chaos
- KPI colors must remain semantic and accessible
- premium feel > loud saturation
- no rainbow dashboards
- no cheap tech gradients

==================================================
GLOBAL UX BEHAVIOR
==================================================

The user experience must feel:
- immediate
- calm
- high-signal
- refined
- easy to trust
- easy to navigate
- not overexplained
- not empty

UX RULES
- every page must have a clear purpose
- every section must answer a real user question
- every CTA must feel intentional
- no dead zones
- no filler sections
- no fake statistics
- no meaningless buzzword blocks
- no giant walls of copy

NAVIGATION
- top-level nav should be extremely clean
- users should understand the ecosystem quickly
- persistent hierarchy matters
- use breadcrumbs and contextual navigation where appropriate
- admin/product areas should feel distinct from public brand surfaces

CONVERSION
- CTAs should feel premium and specific
- avoid “Get Started” everywhere
- use lane-appropriate action language
- forms should be elegant and low-friction
- qualification flows should feel intelligent, not tedious

==================================================
COPY SYSTEM: MASTER RULES
==================================================

The copy must sound like a serious, premium technology and advisory ecosystem.

GLOBAL VOICE
- intelligent
- clear
- concise
- confident
- modern
- strategic
- grounded
- high-trust
- premium
- not cheesy

COPY MUST NEVER SOUND
- generic
- exaggerated
- desperate
- hype-heavy
- jargon-stuffed
- overlong
- robotic
- adolescent
- fake visionary
- padded with buzzwords

COPYWRITING RULES
1. Write with precision.
2. Prefer strong nouns and verbs over adjectives.
3. Avoid cliché phrases.
4. Avoid empty innovation language.
5. Keep claims believable.
6. Make every sentence earn its place.
7. Use short paragraphs with premium pacing.
8. State value clearly.
9. Sound established, even if early.
10. Never oversell what is not yet real.

HEADLINE RULES
- headlines should be sharp and clear
- avoid 14-word startup headlines
- avoid “revolutionizing the future of”
- avoid “AI-powered” unless the context truly matters
- aim for clean, category-shaping statements

SUBHEAD RULES
- explain the value in one crisp beat
- bridge aspiration to specificity
- sound premium and grounded

CTA RULES
- use action language with intent
- examples:
  - Explore the ecosystem
  - Request a private demo
  - View the platform
  - Review capabilities
  - Start a conversation
  - Book an advisory call
  - Access the client portal
  - See the roadmap

MICROCOPY RULES
- labels should be elegant and useful
- helper text should be calm and minimal
- error states should be clear and human
- success states should feel polished and confident

FINAL CREATIVE STANDARD
==================================================

Before finalizing any page, ask:
- Does this feel premium?
- Does this feel original?
- Does this feel strategically clear?
- Does this feel trustworthy?
- Does this feel visually disciplined?
- Does this sound like a serious operator built it?
- Does this avoid startup cliché?
- Would this impress an investor, enterprise buyer, or high-end client?
- Would this still look strong a year from now?

If not, refine until the answer is yes.
