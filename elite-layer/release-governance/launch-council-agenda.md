# Launch Council Agenda Template

## Meeting Details
- **Date**: [date]

## Agenda

### 1. Release Overview (5 min)
- What's being released
- Scope and impact
- Timeline

### 2. Readiness Review (10 min)
- Code quality status
- Test results
- Documentation status
- Support readiness

### 3. Risk Assessment (5 min)
- Known risks
- Mitigation plans
- Rollback readiness

### 4. Go/No-Go Decision (5 min)
| Criteria | Status | Owner |
|----------|--------|-------|
| CI/CD clean | ✅/❌ | [name] |
| Tests passing | ✅/❌ | [name] |
| Docs updated | ✅/❌ | [name] |
| Support ready | ✅/❌ | [name] |
| Security reviewed | ✅/❌ | [name] |
| Rollback tested | ✅/❌ | [name] |

**Decision**: GO / NO-GO / CONDITIONAL

### 5. Rollout Plan (5 min)
- Rollout sequence
- Feature flag configuration
- Monitoring plan
- Escalation contacts

### 6. Action Items
- [ ] [Action] — Owner: [name], Deadline: [date]

## Post-Meeting
- Decision documented and communicated
- Release proceeds or is rescheduled
- Next review scheduled (if conditional)
