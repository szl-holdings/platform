# Request a Security Review — SZL Holdings

## For Prospective Customers & Partners

If you are evaluating SZL Holdings for procurement, partnership, or integration, we are happy to provide:

### Available Upon Request
- Architecture overview documentation
- Data handling and privacy documentation
- Security controls summary
- Incident response overview
- Business continuity summary
- Compliance roadmap

### Available Under NDA
- Detailed infrastructure documentation
- Penetration test results (when available)
- SOC 2 report (when available)
- Data flow diagrams
- Vendor security questionnaire responses

## How to Request

1. **Email**: security@szlholdings.com
2. **Contact form**: /contact (select "Security Review" as topic)
3. **Response time**: Within 2 business days

## What to Include in Your Request
- Your organization name
- Nature of the evaluation (procurement, integration, compliance)
- Specific documents or areas of interest
- Any standard questionnaire you'd like us to complete
- Timeline for your evaluation

## Standard Questionnaires We Support
- CAIQ (Consensus Assessment Initiative Questionnaire)
- SIG (Standardized Information Gathering)
- VSA (Vendor Security Alliance)
- Custom security questionnaires
