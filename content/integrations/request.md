# Request an Integration — SZL Holdings

## How to Request
Email: integrations@szlholdings.com
Or use /contact with topic "Integration Request"

## What to Include
1. **Service name**: What integration do you need?
2. **Use case**: What problem does it solve?
3. **Priority**: Nice-to-have / Important / Critical for adoption
4. **Timeline**: When do you need it?
5. **Alternatives**: Are there workarounds currently?

## Evaluation Criteria
We evaluate integration requests based on:
1. Number of customers requesting it
2. Revenue impact
3. Competitive necessity
4. Implementation complexity
5. Security and compliance requirements
6. Maintenance burden

## Request Status Labels
- **New**: Received, awaiting review
- **Under Evaluation**: Being assessed
- **Approved**: Will be implemented
- **In Progress**: Being built
- **Live**: Available for use
- **Declined**: Not planned (with explanation)
