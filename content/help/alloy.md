# Alloy — Help Guide

## What is Alloy?
Alloy is the execution fabric — workflow orchestration with human-in-the-loop governance. It ensures every action is audited, every decision is approved, and every workflow is traceable.

## Key Features
- **Workflow Builder**: Define and configure automated workflows
- **Approval Center**: Review and approve pending actions
- **Audit Log**: Immutable record of all actions and decisions
- **Skills**: Reusable capabilities that workflows can invoke
- **Governance Dashboard**: Policy management and compliance overview

## Common Workflows

### Approving a Pending Action
1. Open the Approval Center
2. Review the pending approval details
3. Check evidence and context
4. Approve or reject with rationale
5. Action is executed (if approved) and logged

### Viewing Audit Trail
1. Navigate to Audit Log
2. Filter by date, user, action type, or domain
3. Click any entry for full details
4. Export if needed for compliance

### Creating a Workflow
1. Open Workflow Builder
2. Define trigger conditions
3. Add action steps
4. Configure approval gates
5. Set owner and review schedule
6. Activate the workflow

## Troubleshooting
- **Approvals not appearing**: Check your role permissions
- **Workflow not triggering**: Verify trigger conditions and data source
- **Audit log slow**: Try narrowing the date range filter
