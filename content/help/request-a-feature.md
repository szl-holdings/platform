# Request a Feature — SZL Holdings

## How to Submit

### Via Email
Send to: feedback@szlholdings.com
Subject: [Feature Request] Brief description

### Via Contact Form
Visit /contact and select "Feature Request" as the topic.

## What to Include

1. **Product**: Which product would this feature be for?
2. **Problem**: What problem are you trying to solve?
3. **Proposed solution**: How do you imagine the feature working?
4. **Impact**: How would this improve your workflow?
5. **Priority**: How important is this to you? (Nice-to-have / Important / Critical)

## What Happens Next

| Step | Timeline |
|------|----------|
| Acknowledgment | Within 48 hours |
| Review & categorization | Within 1 week |
| Status update (if planned) | When roadmap updated |
| Implementation (if prioritized) | Per product roadmap |

## Request Status Labels
- **New**: Received, awaiting review
- **Triaged**: Reviewed and categorized
- **Planned**: Added to roadmap
- **In Progress**: Being built
- **Released**: Available in the platform
- **Declined**: Not planned (with explanation)

## Popular Request Areas
We're always looking for feedback on:
- Dashboard customization
- Export and reporting options
- Mobile app capabilities
- Integration requests
- Workflow automation ideas
