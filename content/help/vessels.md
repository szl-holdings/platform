# Vessels — Help Guide

## What is Vessels?
Vessels is the maritime operating intelligence platform. It provides fleet command, voyage economics, compliance monitoring, route risk assessment, and exception management.

## Key Features
- **Fleet Map**: Real-time vessel positions on an interactive map
- **Vessel Detail**: Comprehensive vessel profile with history
- **Exception Center**: Flagged issues requiring attention
- **Voyage Economics**: Revenue, cost, and profitability per voyage
- **Maintenance Readiness**: Scheduled maintenance and compliance
- **Route Risk**: Risk assessment for planned routes

## Common Workflows

### Monitoring Fleet
1. Open Fleet Map
2. View vessel positions and status
3. Click any vessel for detail
4. Check alerts and exceptions
5. Review voyage economics

### Managing Exceptions
1. Open Exception Center
2. Review flagged items by severity
3. Assign owner
4. Take corrective action
5. Close exception with notes

### Reviewing Voyage Economics
1. Navigate to Voyage Economics
2. Select voyage or vessel
3. Review revenue, costs, margins
4. Compare against benchmarks
5. Export report if needed

## Troubleshooting
- **Map not loading**: Check network connection, try hard refresh
- **Position data stale**: Check data source connection status
- **Export failing**: Try a smaller date range
