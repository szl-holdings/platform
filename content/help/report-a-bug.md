# Report a Bug — SZL Holdings

## How to Report

### Via Email
Send to: support@szlholdings.com
Subject: [Bug] Brief description

### Via Contact Form
Visit /contact and select "Report a Bug" as the topic.

## What to Include

1. **Product**: Which product were you using? (Lyte, Terra, Vessels, Aegis, Carlota Jo, SZL Holdings)
2. **What happened**: Describe the issue clearly
3. **Steps to reproduce**: What did you do before the issue occurred?
4. **Expected behavior**: What should have happened?
5. **Actual behavior**: What actually happened?
6. **Frequency**: Does this happen every time, or intermittently?
7. **Browser/Device**: Chrome, Safari, Firefox, mobile app, etc.
8. **Screenshots**: If the issue is visual, screenshots help enormously

## What Happens Next

| Step | Timeline |
|------|----------|
| Acknowledgment | Within 24 hours |
| Triage & severity assignment | Within 48 hours |
| Status update | When investigation begins |
| Resolution or workaround | Depends on severity |

## Severity Guide
- **Critical**: Service down, data loss — immediate attention
- **High**: Major feature broken, no workaround — within 24 hours
- **Medium**: Feature degraded, workaround exists — within 1 week
- **Low**: Minor/cosmetic issue — next release cycle
