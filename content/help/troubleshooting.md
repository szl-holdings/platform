# Troubleshooting — Help Center

## Authentication Issues

**Can't sign in**
1. Clear browser cookies
2. Try incognito mode
3. Check if auth provider is available
4. Contact support if issue persists

**Session expired unexpectedly**
1. Sign in again
2. If frequent, check your network stability
3. Contact support if recurring

## Display Issues

**Dashboard shows blank**
1. Hard refresh (Ctrl+Shift+R / Cmd+Shift+R)
2. Check browser console for errors
3. Try a different browser
4. Clear browser cache

**Data not loading**
1. Check your network connection
2. Verify your permissions
3. Clear any active filters
4. Try refreshing the page

## Mobile Issues

**App not connecting**
1. Check WiFi/cellular connection
2. Force close and reopen
3. Clear app cache
4. Check for app updates

## Performance Issues

**Pages loading slowly**
1. Check network speed
2. Close unnecessary browser tabs
3. Try a different browser
4. Report if consistently slow

## Still Stuck?
