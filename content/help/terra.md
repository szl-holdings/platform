# Terra — Help Guide

## What is Terra?
Terra is the real estate operating intelligence platform. It provides portfolio management, distress detection, deal tracking, and market intelligence for real estate operators and investors.

## Key Features
- **Portfolio Dashboard**: Overview of all properties and key metrics
- **Distress Engine**: AI-powered distress property detection
- **Deal Tracker**: Pipeline from opportunity to close
- **Market Intelligence**: Comparable sales, market trends
- **Document Engine**: Generate reports, lender packages, diligence packs
- **Property Map**: Geographic visualization of assets

## Common Workflows

### Reviewing a Distress Alert
1. Open the Distress Engine
2. Review flagged properties
3. Open property detail for context
4. Create a deal or add to watchlist
5. Start diligence if pursuing

### Managing a Deal
1. Open Deals from the sidebar
2. Select or create a deal
3. Track pipeline stage
4. Attach documents and notes
5. Move through approval review

### Generating a Lender Report
1. Navigate to Document Engine
2. Select Lender Report template
3. Choose properties to include
4. Generate and review
5. Export as PDF

## Troubleshooting
- **Map not loading**: Check browser permissions for location
- **Properties not showing**: Verify filters and data source status
- **Report generation slow**: Large reports may take 30+ seconds
