# Lyte — Help Guide

## What is Lyte?
Lyte is the business observability command plane. It helps executives and operators see everything happening across the organization and make decisions quickly.

## Key Features
- **Executive Command Dashboard**: Bird's-eye view of all signals and metrics
- **Signal Queue**: Prioritized list of events requiring attention
- **Advisory Intelligence**: AI-powered analysis and recommendations
- **Engagement Workflow**: Structured client engagement tracking
- **ROI Calculator**: Quantify the value of observability
- **Document Engine**: Generate reports and memos

## Common Workflows

### Triaging a Signal
1. Open the signal queue from the dashboard
2. Review the signal context and priority
3. Assign an owner or escalate
4. Update status as work progresses

### Viewing Executive Summary
1. Navigate to the Executive Command dashboard
2. Review key metrics and trends
3. Drill into any area for details

### Running an Advisory
1. Open Advisory Intelligence
2. Select the analysis type
3. Review AI-generated insights
4. Take action or export findings

## Troubleshooting
- **Dashboard not loading**: Try hard refresh, check permissions
- **Signals not appearing**: Check filters, verify data source connections
- **Export failing**: Check browser download settings, try a different format
