# Getting Started — Help Center

## First Steps
1. **Sign in** using your authentication provider
2. **Navigate** to your product dashboard
3. **Explore** the key workflows for your role
4. **Set up** any personal preferences or filters

## Role-Based Quick Starts

### Executive / Decision Maker
- Start at the command dashboard
- Review the executive summary
- Check pending approvals
- Review key metrics

### Operator
- Start at the operational dashboard
- Check your assigned queues
- Process pending items
- Review alerts and exceptions

### Viewer / Analyst
- Start at the analytics dashboard
- Review reports and trends
- Export data as needed
- Set up saved views
