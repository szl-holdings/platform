# Aegis — Help Guide

## What is Aegis?
Aegis is the unified defense and intelligence command center. It provides SOC operations, threat intelligence, incident response, vulnerability management, and governance for security teams.

## Key Features
- **Command Home**: Unified security overview
- **Investigations Board**: Active investigation tracking
- **Decision Console**: AI-assisted security decisions
- **XDR Console**: Extended detection and response
- **MITRE ATT&CK Mapping**: Threat framework alignment
- **Threat Intel**: Intelligence feed aggregation
- **Governance Suite**: Compliance, analytics, executive reports

## Common Workflows

### Investigating an Incident
1. Open the Investigations Board
2. Select the incident
3. Review timeline and evidence
4. Update status and assign investigator
5. Document findings
6. Close with resolution

### Running a Simulation
1. Navigate to Simulation Panel
2. Select scenario type
3. Configure parameters
4. Execute simulation
5. Review results and recommendations

### Governance Review
1. Open Enterprise Governance
2. Review compliance status
3. Check trust analytics
4. Generate executive report

## Troubleshooting
- **Alert overload**: Use filters to focus on critical/high severity
- **Investigation timeline slow**: Try narrowing the date range
- **Simulation not running**: Check parameter validity
