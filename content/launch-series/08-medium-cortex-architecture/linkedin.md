The challenge of multi-domain operations is not information abundance.

It is context switching.

An operator responsible for fleet decisions, real estate portfolio health, and security posture simultaneously does not need three separate dashboards. They need one interface that surfaces what matters most — across all three domains — without requiring them to know in advance which domain is producing the most consequential signal at any given moment.

That is what CORTEX is.

CORTEX is the unified mobile command layer for the SZL Holdings platform — a native iOS and Android application that surfaces cross-domain intelligence and governed decision queues across all six domain packs in a single interface.

The non-obvious architectural property: governance does not change depending on which interface the operator is using.

A Covenant Policy requiring senior authorization for a containment action applies identically on mobile and desktop. The Proof Chain record from a mobile-confirmed action is structurally identical to a desktop record. Biometric authentication is integrated into the action confirmation flow — not just as a login gate, but as a governance checkpoint.

The primary mobile UX pattern: cross-domain badge aggregation.

An operator sees their morning exception queue as a single ranked list across all domains — not a separate notification from each app. CORTEX surfaces it by urgency score, drawing from the cross-domain Outcome Graph and the operator's current Covenant Policy authorization level.

The governance travels with the operator because it is platform-level, not interface-level.
