# Operator Tour — 15 Minutes with SZL Holdings

## What You'll See
A hands-on walkthrough of the key workflows operators use daily across the platform.

## Tour Steps

### Section 1: Signal Triage (3 min)
**Product**: Lyte
1. Open the signal queue
2. Sort by priority
3. Open a high-priority signal
4. Review context and evidence
5. Assign an owner
6. Update status to "in progress"

### Section 2: Workflow Execution (3 min)
**Product**: Alloy
1. Open the workflow list
2. Select a workflow run
3. Review execution steps
4. Check the audit trail
5. Approve or review a pending action
6. See the immutable log entry

### Section 3: Domain Operations (4 min)
**Product**: Choose one — Terra, Vessels, or Aegis

**Terra Path**:
1. Open property dashboard
2. Check distress engine alerts
3. Open a property detail
4. Review deal pipeline
5. Generate a lender report

**Vessels Path**:
1. Open fleet map
2. Select a vessel
3. Review voyage economics
4. Check exception queue
5. Resolve an exception

**Aegis Path**:
1. Open command home
2. Review incident queue
3. Open an investigation
4. Check threat intel
5. Run a simulation

### Section 4: Content Distribution (3 min)
**Product**: SZL Holdings Distribution OS
1. Open admin panel (/admin/distribution)
2. Review articles CMS
3. Check content calendar
4. View analytics dashboard
5. Review lead pipeline

### Section 5: Governance & Trust (2 min)
1. View the trust center (/trust)
2. Check the audit trail
3. Review feature flags
4. Check release notes

## Key Takeaways
- Every action is logged
- Every decision requires evidence
- AI proposes, humans approve
- Distribution is systematic, not ad hoc
