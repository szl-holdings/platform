# Glossary — SZL Holdings

| Term | Definition |
|------|-----------|
| **Alloy** | SZL's execution fabric — workflow orchestration with human-in-the-loop governance |
| **Audit Trail** | Immutable log of every action, decision, and approval in the system |
| **Campaign** | A coordinated content distribution effort with UTM tracking |
| **Distribution OS** | SZL's built-in content publishing and distribution platform |
| **Editorial Pillar** | A thematic content category (e.g., "Business Observability", "Maritime Intelligence") |
| **Evidence Retrieval** | AI-powered search using hybrid methods (semantic + keyword) with reranking |
| **Feature Flag** | A toggle controlling feature visibility for progressive rollout |
| **HITL** | Human-in-the-Loop — requiring human approval before AI actions execute |
| **Kill Switch** | An operational flag that immediately disables a feature |
| **Lead** | A potential customer captured through marketing or inbound channels |
| **Lyte** | SZL's business observability command plane |
| **Operator** | A user with domain expertise who uses the platform daily |
| **Policy Gate** | A rule that must pass before an AI action is allowed to proceed |
| **Counsel** | SZL's legal intelligence product |
| **Propose-Only Mode** | AI suggests actions but does not execute without human approval |
| **RBAC** | Role-Based Access Control — permissions based on user roles |
| **SCIM** | System for Cross-domain Identity Management — enterprise user provisioning |
| **Signal** | An event or data point that triggers attention or action |
| **Tenant** | An organization with isolated data and configuration |
| **Trust Center** | Public-facing pages documenting security, privacy, and compliance posture |
| **UTM** | Urchin Tracking Module — URL parameters for campaign attribution |
| **Workflow Run** | A specific execution instance of a defined workflow |
