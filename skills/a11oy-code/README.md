# A11oy Code Skill Pack

This skill pack provides the copy-ready prompts, checklists, agent roster, and operating instructions for the A11oy agentic system. It is designed for use by Replit agents, Codex sessions, Cursor IDE, and human contributors working in the SZL Holdings monorepo.

## Contents

| File | Purpose |
|------|---------|
| `SKILL.md` | Full skill definition and operating instructions |
| `prompts.md` | Eleven copy-ready agent prompts for the Core Execution Loop |
| `checklist.md` | Checklists for preflight, patch, screenshot, public claim, security, release, and proof |
| `agent-roster.md` | All 18 named agents with one-line roles |

## How to Use

1. Read `SKILL.md` for the full context and operating instructions.
2. Use `agent-roster.md` to identify which agent to invoke for your task.
3. Use `prompts.md` to copy the appropriate agent prompt into your session.
4. Use `checklist.md` to verify your work before committing.
