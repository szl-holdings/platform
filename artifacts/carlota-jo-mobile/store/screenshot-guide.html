Carlota Jo — Client App

Screenshot capture guide for App Store and Google Play submission

Capture Steps

  1. Start the app: cd artifacts/carlota-jo-mobile && npx expo start --web
  2. Open Chrome or Safari and navigate to the local Expo dev URL
  3. Open Developer Tools → Device Toolbar (Ctrl+Shift+M / Cmd+Opt+I)
  4. Set the viewport to each device size listed below
  5. Navigate to each screen and capture using your screenshot tool
  6. Save files to the output paths listed in store/screenshot-manifest.json

Screens to Capture (5 screens)

  • Screen 01: Dashboard — Portfolio overview and engagement status
  • Screen 02: Secure Messaging — Encrypted advisor communication
  • Screen 03: Document Vault — Agreements and reports
  • Screen 04: Meeting Schedule — Advisory session calendar
  • Screen 05: Profile — Account and access settings
